# UI and design system

Base-layer reuse, `AreaRolavel`, `carregando`, tokens and no-dash are in `engineering.md`. The reasoning lives in `docs/design-system/` (read the matching file, do not copy it here).

## Layers
- Two layers: `components/ui/` is the BASE (adjusted once); `components/` is PRODUCT and consumes it. Search the base for a variant before writing `className`.  (why: docs/design-system/camada-base.md)
- For a `<form>`/`<section>` that IS the card use `cn(cardVariants(), ...)`, not `Card asChild`.  (why: docs/design-system/camada-base.md)
- Base-layer rules: geometry lives in the cva `size` (`size="none"` = no geometry); never `[&_svg]:size-4`; never a focus ring in a component (focus is global); `data-slot` AFTER the spread, and a `data-slot` passed from outside is ignored (mark states with another attribute, e.g. `data-em-breve`); never read an ancestor's `data-state` (pass state by prop); `tailwind-merge` knows the type scale via `extendTailwindMerge` in `lib/utils.ts`; a Radix root renders no element, so chained triggers attach to the SAME element.  (why: docs/design-system/camada-base.md)
- `Button carregando`: with `asChild` the child goes ALONE (no `false` sibling, it breaks the Slot). `disabled` only for missing data.  (why: docs/adr/2026-09-26-button-carregando-prop.md)
- Field inside a table of pairs: `Input` variant `sutil` (border `line`, not `line-soft`).  (why: docs/adr/2026-09-19-input-sutil-variant.md)
- Search field with magnifier = `CampoBusca` (`components/ui/campo-busca.tsx`: frame classes in `className`, input classes in `classeDoCampo`, optional clear `x`); thin progress bar = `Medidor` (`components/ui/medidor.tsx`, `tom` marca/neutro/aviso/perigo, `rotulo` makes it an accessible meter). Never hand-write either again.  (why: docs/adr/2026-10-13-ai-usage-cap-in-tokens.md)
- A chart is drawn ONLY through `components/ui/chart.tsx` (shadcn `chart`, Recharts, version pinned) (the old heatmap component was deleted on 16/10/2026, the owner chose the column charts); never import `recharts` in a screen component for its own styling, never a hex in a `ChartConfig` (use `--chart-*` tokens of `app/globals.css`; brand + neutral, a one-hue ramp for slices, green/amber/red stay state). Every chart has a hover and focus tooltip, a legend with two series or more (identity never by color alone, `ChartLegenda` takes the color explicitly), and a text table view (`ChartTabela` of `chart.tsx`: `sr-only` on a wrapper `div`, never on the `table`, rows carry the `data-*` the tests read). Pure chart logic (axis marks, slice builder, label split, period unit `unidadeDoPeriodo`) lives in `lib/`, never in the component; chart-heavy tabs load with `dynamic()`, and `balao.ts` must not import `recharts`. Pick the form by the data (columns over time, donut for up to five parts of a whole, horizontal bars for long names and order, heatmap for a grid), no dual axis. Bars are `path.recharts-rectangle` and tick values `.recharts-cartesian-axis-tick-value` in the DOM.  (why: docs/adr/2026-10-15-charts-recharts-in-base-layer.md)
- `Stat` period legend (`StatLegenda`) is mandatory. `sheet` width is a variant (`padrao` 520, `largo` 1040), never className on a screen.  (why: docs/design-system/camada-base.md)

## Scroll and surface
- Every scrollable dissolves at its edges: `<AreaRolavel>` or the `fade` prop of `ScrollArea`; `useDissolverRolagem` only for other tags or `temMais`. Degrees: `DISSOLVER_PADRAO` 32, `DISSOLVER_LISTA` 72, `DISSOLVER_BALAO` 80. Exception: a scroll area with a `sticky` child gets no mask (`/agente`). `e2e/rolagem.design.spec.ts` fails on any unmasked scrollable.  (why: docs/design-system/fundamentos-superficie.md)
- The app shell (`h-dvh`) never scrolls the page: anything taller than a short window scrolls INSIDE its own area. The `NavRail` items live in an `AreaRolavel` (`data-slot="rail-itens"`) between the fixed brand and footer (a rail of 647px made every screen scroll below its card on a 650px window). `e2e/central-clientes-ajustes.design.spec.ts` checks document height equals window height at 560, 640 and 720.  (why: docs/adr/2026-10-15-central-layout-adjustments.md)
- Never leave an `absolute` or `sr-only` element inside a scroll area without a positioned ancestor inside that area: its containing block becomes the page and it stretches the document (`ChartTabela` wraps its `sr-only` table in a `relative` div for this reason; the symptom was an empty strip under the card plus a page scrollbar). Measure up the tree when a page scrolls: `html.scrollHeight` greater than `innerHeight` with `body` fine means an absolute descendant.  (why: docs/adr/2026-10-15-central-layout-adjustments.md)
- `Medidor`: the track is `line-strong` (visible on `bloco` and `raised`, light and dark), the `neutro` fill is `ink-3`. A chart tooltip is always above sibling overlays (`z-50` on `.recharts-tooltip-wrapper` in `ChartContainer`). A column above a reference is a state series in `--chart-acima` (amber), never a hue of its own.  (why: docs/adr/2026-10-15-central-layout-adjustments.md)
- The goal-progress bar is its own base component, `MedidorDeMeta` (`components/ui/medidor-de-meta.tsx`, `valor`, `marcador` 0 to 100, `estado` `bom`/`ruim`): ONE track in the light tint of the state, the solid fill, a round marker at the ideal and a hatched segment between the fill and the marker; the screen writes the sentence (color is never the only clue) and the state comes from `posicaoNoRitmo` (`lib/custo-ia.ts`), never recomputed in the component. `Medidor` stays the thin bar. A trend inside a card is `ChartSparkline` (`chart.tsx`: a thin area in the brand color, tooltip with the point label and value, `aria-hidden` and without the Recharts focus layer because the card text already says the value and the big chart of the tab has the text table). A variation is the panel's `Selo` over `lib/delta.ts` (`calcularDelta` with `piso: 0` for numbers with no readable absolute, `deltaDuracao` for a time), wired with the "comparado com" legend and the sparkline by `IndicadorComparado` (`components/admin/IndicadorComparado.tsx`, kept out of `pecas.tsx` because it pulls Recharts): arrow for what happened, state color for what it means, never green for "more cost". A choice list in a menu uses `DropdownMenuItemMarcado` (check mark and `aria-current`), never a hand-written item. The non-highlighted bar of a "pick the peak" chart is `--chart-barra-neutra`.  (why: docs/adr/2026-10-16-central-picos-plan-caps-ptax-and-cards.md)
- No scroll shadow. One signal per fact; the dissolution must be LARGER than the item it dissolves. `SetaMais` only where scrolling is the navigation (conversation, conversation list).  (why: docs/design-system/fundamentos-superficie.md)
- A list that grows at the top (paginated conversation) never loads while the scrollbar thumb is held, and `ScrollArea` recomputes the thumb itself from live sizes on every scroll (one frame after Radix) and on content or viewport resize, writing the thumb `height` directly (Radix measures late and its numbers can stay stale). Test the thumb against `scrollTop` with `/design?mensagens=150` (`e2e/rolagem-barra.design.spec.ts`).  (why: docs/adr/2026-10-05-conversation-scrollbar-thumb-follows-content.md)
- `.fundo-rede` (`components/FundoRede.tsx`) is the ONLY texture: behind the message area, dissolved on four edges, 960px column.  (why: docs/design-system/fundamentos-superficie.md)
- Card surface is `bg-raised`; card padding 24px (`p-6`), exceptions: dashboard headline and a block inside a card (16px).  (why: docs/design-system/fundamentos-geometria.md)

## Color and type
- Each hue has 4 roles: `fill`, `on`, `ink`, `surface`/`line`. Text/icon uses `ink` (`text-brand-ink`, `text-warn-ink`), never `fill`; `ink` is never a background. Ink has 4 levels; `ink-faint` is never text; minimum text 12px.  (why: docs/design-system/fundamentos-cor.md)
- `--brand-grad-end` (#4464d4) only for brand gradient, symbol and decorative surface from 28px; never text, icon or state. Avatar color comes from `avatarPair()` (`lib/inbox.ts`).  (why: docs/design-system/fundamentos-cor.md)
- Type roles: `text-titulo` 18 (page), `text-cartao` 16 (block with own structure), `text-rotulo` 12 caps (label of a value, simple card, collapsible sub-block). The last two are not interchangeable. A type role never reuses a color name.  (why: docs/design-system/fundamentos-tipografia.md)
- Removed names must not return: `bg-conteudo`, `--s-conteudo`, `text-display`, tabs `segmentado`, `bg-sunken|inset|lista|lista-sel|composer|sub|painel|chat`, `--surface`, `--panel`, `text-ink-muted`, `text-ink-dim`, `.btn-primary`, `.glass`, `.panel`, `--radius-2xl`, `--color-accent`, `--color-ia`.  (why: docs/design-system/pendencias.md)

## Motion
- Animation is house CSS (`.anim-flutuante`, `.anim-fundo`, `.msg-in`, `.anim-lateral`, `.painel-*`), no `tw-animate-css`, no Motion. Tailwind v4 emits `-translate-x-1/2` as the `translate` property, so a keyframe that repeats it ADDS: `.anim-flutuante` must not touch `translate`; `sheet` has its own `.anim-lateral`. Honor `prefers-reduced-motion`.  (why: docs/design-system/fundamentos-animacao.md)

## Copy and inbox behavior
- Fixed screen text never assumes appointment, patient or scheduling (mixed audience); segment language comes from the preset.  (why: docs/adr/2026-08-26-beta-mvp-scope-and-menu.md)
- Inbox list opens on `Hoje` (`Hoje`/`7 dias`/`Tudo`, `data-slot="inbox-periodo"`), rolling civil day in America/Sao_Paulo (`dentroDaJanela`/`diaSP`, `lib/inbox.ts`). A conversation with open `handoff_at` is NEVER hidden by the time filter (`needsYou(it) ||` in `components/ContactSidebar.tsx`). Chip counts follow the window; search ignores it.  (why: docs/adr/2026-09-19-inbox-opens-on-today.md)
- Menu (`components/NavRail.tsx`): Painel first, Pedidos, Conversas, Contatos, Pipeline, Agente (owner), Equipe; "Em breve" = Follow-up. At the END, a separate section titled `BRAND.secaoDoDono` (`lib/brand.ts`) with the product owner's tools, Campanhas and Clientes (`doDono` + `adminOnly`, server decision `ehAdmin`), grouped the same way inside "Mais" on mobile. A tenant never sees that section.  (why: docs/adr/2026-08-26-beta-mvp-scope-and-menu.md)
- The tenant's contacts list is "Contatos" on every screen (menu, title, empty states, buttons) and lives at `/contatos` and `/contatos/[id]`; the tables, the lib names and the `clientes-*` data slots stay. In the product owner's central (`/clientes`, `docs/adr/2026-10-14-clientes-central-with-tabs.md`) the tenants are "Clientes". "cliente" in conversation copy ("O que o cliente escreveu") and in AI prompts is a different meaning and stays.  (why: docs/adr/2026-10-13-ai-usage-cap-in-tokens.md, docs/adr/2026-10-14-clientes-central-with-tabs.md)
- Situation and alert chips of the central use the `Badge` variants `estado-bom|aviso|perigo|neutro` (tone from `lib/admin-alertas.ts`, never decided in the chip). The menu item "Clientes" (`adminOnly` in `NavRail`) shows only when the server passes `ehAdmin`.  (why: docs/adr/2026-10-14-clientes-central-with-tabs.md)
- Mobile: bottom bar has Pedidos where Pipeline was; Pipeline lives in "Mais".  (why: docs/adr/2026-09-30-pedidos-detail-is-a-request-sheet-not-a-chat.md)
- `Stat` has an `elevado` variant because `--s-bloco` equals `--canvas` in the light theme: a `bloco` card on the canvas would be invisible. Use `elevado` there.

## Cursors and label colors
- Everything clickable shows `cursor: pointer`, set in the base layer (`components/ui/*`, reset in `app/globals.css`), not per screen. Disabled is `not-allowed` (or `progress` for `carregando`). A product element with `onClick` that is not a `button`/`a` is a smell: use a `Button` variant. `e2e/cursor.design.spec.ts` checks the computed cursor on every `/design` route.  (why: docs/adr/2026-10-02-base-layer-cursors-and-label-palette.md)
- Tag and funnel-stage colors come from ONE palette (`lib/rotulos.ts`, `chaveDoRotulo`, eight hues, never green/amber/red, tokens per theme). Stored colors are mapped at render; never rewrite the DB for this.  (why: docs/adr/2026-10-02-base-layer-cursors-and-label-palette.md)
- `ink-faint` is never text, with one documented exception: the empty-state XX mark. Everything else that was ink-faint text is `ink-3`.  (why: docs/adr/2026-10-02-base-layer-cursors-and-label-palette.md)
